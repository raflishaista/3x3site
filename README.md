# 3x3site

![Home page](https://i.imgur.com/WJbJeRA.png)

A personal page for showing your favorite books, films, games, food, or anything else in image grids from 1×1 to 5×5, including rectangular layouts. Edit your profile, upload images or animated GIFs, add descriptions and links, and drag images or collections into your preferred order.

Built with plain HTML, CSS, and JavaScript. Accounts, profiles, images, and collections are saved with Supabase.

Register using an email code, then share your /username page.

![Profile edit page](https://i.imgur.com/hK0rnJw.png)

A separate page for edits, allowing users to edit their profile picture, name, bio, and the 3x3's, and the orders.

![3×3 editor](https://i.imgur.com/yUt5wTP.png)

Click on a 3x3 to edit that 3x3, allowing you to add images, image formats/layouts, and border options.

![Description and link editor](https://i.imgur.com/m8ZnP4d.png)

Edit an image's description in a grid to edit the description and a hyperlink.

## Run locally

With Node.js and npm installed, run this from the `three-by-three` project folder:

```sh
npm run dev
```

Open [localhost:3313](http://localhost:3313). No dependency installation or build step is needed.
